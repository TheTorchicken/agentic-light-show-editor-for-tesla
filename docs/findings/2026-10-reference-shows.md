# Findings: how existing shows use the channels (October 2026)

Frame-by-frame analysis of Tesla's own example shows, three community shows built
for the 2024+ Model 3 and the 2025 Model Y, and two shows generated by an AI agent
driving xLights. The show files themselves are not in this repo.

## Format facts

- Every show the car accepts is FSEQ v2.0 uncompressed with exactly 48 or 200
  channels. All modern shows use 200.
- Tesla's public layout assigns all 200 channels. Beyond the 46 shared lights and
  closures it covers the Cybertruck bars and the interior RGB.
- Tesla's public repo has no 2025+ layout and no LICENSE file. Two open issues ask
  for Model Y Juniper mappings and have no reply from Tesla.

## Tesla's own shows

- Shows for the Model S/3/X/Y only use the ramp command values on lights:
  0, 25, 51, 63, 127, 191, 204, 229, 244, 255. No continuous fades.
- Cybertruck shows drive all 60 front-bar and 52 rear-bar LEDs at fine-grained
  brightness, with about 57,000 value changes in 90 seconds.

## Community shows for the new Model 3 and Model Y

| Show | Car | Channels used | Notes |
|---|---|---|---|
| This Is Halloween | Model 3 (2024+) | 19 exterior + interior RGB | On/off only. Channels 4-6 always move together. Left/right always mirrored. 50 ms frames. |
| Starships | Model 3 (2024+) | 19 exterior + interior RGB | Same creator and style. Front turns use 26 brightness levels. |
| Zelda, Juniper version | Model Y (2025) | 21 exterior + interior RGB | 80-107 brightness levels per light, as clean linear ramps. Started as a Cybertruck show; the light-bar channels were removed. |

What all three have in common:

- **No signature lights (ch 5/6), fogs, aux park, side markers or closures.**
- **No light-bar channels**, even on the Model Y show.
- **Left and right always identical.**

In a filmed Model 3 show, the variety of headlight shapes comes from switching
different headlight channels in combinations. Each channel lights a physically
different part of the lamp. Nothing in the data addresses individual matrix segments.

## Unverified community claims (to be checked by the probe)

From a third-party app developer in teslamotors/light-show issues #144 and #166:

- Model Y Juniper front bar = ch 47-106 (60 white LEDs), rear bar = ch 111-162
  (52 red LEDs), each with full brightness control.
- Channels 4-6 are one physical output on Model 3/Y. Tesla's own README also says this.
- Aux park is merged with the side markers on the Model Y.
- Interior RGB segment order differs from the names in Tesla's layout.

Nothing at all is published for the 2024+ Model 3.

## The AI-generated baseline

Two shows made by an agent driving xLights, rated "mid" and "bad" by the owner:

- On/off only. No ramp codes, fades, closures or light bars.
- Headlights on for 55-80% of the runtime, so there is little contrast.
- The worse show drives all four headlight channels and the signature as one
  identical block.

That is the bar to clear, and the list of things the design skills must teach:
contrast and rest, independent left/right, using every light group, fades, and
saving closures for peaks.
