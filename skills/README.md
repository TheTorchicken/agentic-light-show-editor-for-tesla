# Skills

Design knowledge for whoever choreographs a show, agent or human, as plain Markdown.

Start with `routing/SKILL.md`: it picks the genre skill for a song. Then read:

- `design-fundamentals/SKILL.md`: principles every show follows.
- `genres/`: one file per kind of music (electronic, cinematic-orchestral, hip-hop-spoken,
  musical-theatre). Add a new one when a song doesn't fit; see routing.
- `vehicles/`: what each car's lights and moving parts can do, measured on real cars.

Every rule here came from a real show and real feedback. When a review proves a rule
wrong, fix the rule and say which show taught it.
