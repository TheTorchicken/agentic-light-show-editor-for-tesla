# Grief (KzX, Stalemate): show plan

Car: 2027 Model 3. Tempo 84.5 BPM (half-time feel; drums hit every beat, 0.705 s).
One bar is 2.82 s. Instrumental and bass-led, with a stuttered first drop, a long
second drop, a hard breakdown and a short vocal outro.

Owner's brief: it should have every kind of moment: strobes, fades and movement.

## Light mapping (kept consistent across the song)

| Musical element | Lights |
|---|---|
| Melodic stabs (intro, builds) | DRL strips, alternating sides, quick ramp on and slow ramp off |
| Drum hits | Front outer beams + brake, front and rear answering each other |
| Big accents and drop hits | Everything snaps on, inner beams decay |
| Eighth-note movement | Amber diagonal chase: front left → rear right → front right → rear left |
| Hats / 16ths in climaxes | Side repeaters and plate strobing |
| Stutter gaps in drop 1 | True blackout in the gap, then a burst |
| Bass swells | Interior color brightness |
| Vocal outro | Inner beams + DRL slow 2 s fade, warm interior |

second peak at the end of drop 2, a collapse, one more climb, then a quiet, warm ending.
